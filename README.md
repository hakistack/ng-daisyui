# Hakistack

Open-source building blocks for Angular applications. This monorepo holds every Hakistack product; each one is
installed, versioned and released on its own.

| Product | What it is | Install | Docs |
|---|---|---|---|
| **[@hakistack/ng-daisyui](projects/hakistack/ng-daisyui/README.md)** | Angular 21 components on daisyUI 5 / Tailwind CSS 4: forms, data grid and table, select/date/time inputs, overlays, rich editor, document and PDF viewers, tree, virtual scroller | `npm i @hakistack/ng-daisyui` · `ng add @hakistack/ng-daisyui` | [README](projects/hakistack/ng-daisyui/README.md) · [CHANGELOG](projects/hakistack/ng-daisyui/CHANGELOG.md) · docs site (`npm start`) |
| **[@hakistack/i18n](projects/hakistack/i18n/README.md)** | Type-safe i18n for Angular on top of Transloco: translations authored in `.ts`, typed keys and JSON generated by a CLI | `npm i @hakistack/i18n @jsverse/transloco` | [README](projects/hakistack/i18n/README.md) |
| `hakistack-engine` (internal) | Rust crates compiled to WebAssembly: table/tree/search/form kernels, spreadsheet, image and PDF engines used by ng-daisyui | — not published | [README](hakistack-engine/README.md) |

The two npm packages are independent: `@hakistack/i18n` works in any Angular app without ng-daisyui, and
ng-daisyui has its own label system without i18n.

## Repository map

```
projects/hakistack/ng-daisyui   @hakistack/ng-daisyui (src/public-api.ts is the only entry point)
projects/hakistack/i18n         @hakistack/i18n (runtime, /engine, CLI, schematics)
projects/demo, shared-demos     documentation site and live examples (daisyUI 5)
projects/demo-v4                the same demos on daisyUI 4 / Tailwind 3 (legacy styles path)
hakistack-engine/               Rust/WASM workspace (private)
tests/consumer-smoke*           clean apps that install each packed package
e2e/                            Playwright + axe
scripts/                        build steps; scripts/workspace/ = monorepo tooling
docs/                           architecture, ADRs, audits, maintenance
```

How the pieces fit and which rules keep them apart: [docs/architecture/monorepo.md](docs/architecture/monorepo.md).

## Quick start

Requirements: Node ≥ 22, npm 11. Rust (stable) + `wasm-pack` only to rebuild the WASM engines — their generated
output is committed.

```bash
npm ci                         # toolchain, both libraries, and demo-v4 (npm workspace)
npm start                      # docs site on http://localhost:58790
npm run build                  # both packages → dist/hakistack/{ng-daisyui,i18n}
npm test                       # unit tests of both packages
npm run lint                   # ESLint + dependency boundaries
```

Per product: `build:ui` / `build:i18n` / `build:engine`, `test:ui` / `test:i18n` / `test:engine`, `validate:ui`,
`test:consumer:i18n`… — the full command table is in [CONTRIBUTING.md](CONTRIBUTING.md).
